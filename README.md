# Leela Padala — Portfolio

My cybersecurity background, recent open-source work, and Python projects.

**[Visit the portfolio →](https://leela-padala.github.io/)**

Built with HTML, CSS, and JavaScript. Includes light and dark themes, a sample login-log walkthrough, and layouts for phones and larger screens.

To view it locally:

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000`. Edit `index.html` for content, `styles.css` for the layout, and `script.js` for the theme and sample logs.
