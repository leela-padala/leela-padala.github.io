# Leela Padala — Portfolio

My cybersecurity background, recent open-source work, and Python projects.

**[Visit the portfolio →](https://leela-padala.github.io/)**

Built with HTML, CSS, and JavaScript. Includes light and dark themes, an illustrative login-log walkthrough, and layouts for phones and larger screens.

Recent work includes Azure App Service and SQL inventory fixes in Prowler, plus contributions to pySigma and Sigma. PR statuses were checked on October 18, 2026. The SOC Log Analyzer is a private practice project; the on-page examples use synthetic events.

To view it locally:

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000`. Edit `index.html` for content, `styles.css` for the layout, and `script.js` for the theme and sample logs.

The Newsreader font is hosted locally under `assets/fonts/`; its SIL Open Font License is included there. The site has no build step or runtime dependencies.
