SOC Log Analyzer

Checking login records with Python.

The problem
Login exports can contain repeated failures or a successful login after several failures. These patterns need a closer look.

I built a Python command line tool that validates CSV and JSONL logs, looks for repeated failures, password spray patterns, and success after failures, and writes JSON and Markdown reports.

The result
The tool writes JSON and Markdown reports for review. It helps organize an investigation; an alert still needs supporting evidence.

Input
CSV / JSONL authentication exports
Output
Repeatable investigation reports
Scope
Independent learning and investigation aid
